The Rising Floor

Each era, yesterday's scarce skill becomes the new baseline: a stacked chart of how the floor of data and computing skills has risen since the 1880s.
Jul 2026 · Supporting analysis
TL;DR
  • A single stacked chart: eight columns – seven eras since the 1880s plus 2025→? – where every layer is a skill that was once the bottleneck and is now baseline.
  • Reading rule: the highlighted layer is the currently scarce skill; every layer beneath it got tooled and the value moved one layer up.
  • The eighth column shows all seven layers commoditised and a dashed, unclaimed layer on top – Domain Judgment – marked as a hypothesis, not a record.

Each era, yesterday's scarce skill becomes the new baseline. The scarce skill (highlighted, glowing) is always one layer above where the previous era left off.

This page is a single chart: a stacked view of how the floor of data-and-computing skills has risen, era by era, since the 1880s. For the full write-up of each era, see The Scarcity Ladder – A Timeline. For the argument this builds toward, see "The Floor Keeps Rising".

Every column is a moment in time. Every layer beneath the glowing one is a skill that used to be the bottleneck and now isn't – it got tooled, and the value moved up. The 2025 → ? column shows all seven layers as fully commoditised baseline, with a dashed, unclaimed layer on top: Domain Judgment. That layer is marked differently on purpose. It hasn't happened yet, and – unlike every layer beneath it – it might not happen the same way. The other seven columns are a record. The eighth is a question.
